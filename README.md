# Ciber CDM · Incidentes de Ciberseguridad — apuntes (alumnado)

Apuntes del módulo **MP5021 Incidentes de Ciberseguridade** (Curso de Especialización en Ciberseguridad). Versión de **alumnado**: sin soluciones ni notas docentes.

- Sitio web autocontenido (`index.html`, un solo fichero, sin dependencias que compilar).
- Laboratorio con **VirtualBox + Vagrant** (red interna aislada `172.21.10.0/24`, Debian 12).
- De momento la **UD1** aparece desarrollada; el resto de unidades listan sus actividades y tareas en el menú, con el contenido pendiente de publicar.

## Publicar con GitHub Pages
En el repositorio: **Settings → Pages → Source: Deploy from a branch**, rama `main`, carpeta `/ (root)`.
El fichero `.nojekyll` evita que GitHub procese el sitio con Jekyll.
